## 3. Tone down the technology tag styling on the project cards

The coloured pill badges on the project cards (COPILOT COWORK, DYNAMICS 365, AI BUILDER, etc.) are currently too visually dominant — saturated background colours with white bold uppercase text. They look like buttons and compete with the project titles and metrics.

**Change the styling to:**
- Background: light grey (e.g., #f0f0f0 or equivalent in your design system) or very light blue.
- Text: dark grey or near-black, regular weight (not bold), normal case (not uppercase).
- Font size: slightly smaller than the current size — the tags should be clearly secondary to the title and metric.
- Keep the pill/rounded shape.
- Keep the same tags and the same order on each card.

The tags should feel like metadata labels, not action buttons. Think GitHub repository language tags or LinkedIn skill pills — subtle, readable, secondary.

This styling change must apply to:
- The 2 project cards on the Home page.
- All 4 project cards on the /projects page.
- Consistent styling across both pages.
